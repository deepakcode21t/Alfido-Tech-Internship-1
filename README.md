# Alfido-Tech-Internship

**Name:** Deepak Thapa  
**Company:** Alfido Tech  
**Domain:** MERN Stack Developer  
**Task:** Task 1 – RESTful API  

## 1. Introduction

This task focused on developing a RESTful API using **Node.js, Express.js, MongoDB, and Mongoose**. The API manages product data and performs CRUD operations.

## 2. Objectives

- Build a RESTful API using Node.js and Express.js.
- Connect the application with MongoDB using Mongoose.
- Implement CRUD operations for products.
- Add data validation and error handling.
- Test and verify API functionality.

## 3. Task Completed

**Task 1: RESTful API (Node + Express + MongoDB)**

Created a product management API supporting:

- **POST** – Create product
- **GET** – Retrieve products
- **PUT/PATCH** – Update product
- **DELETE** – Delete product

## 4. Tools & Technologies

**Node.js | Express.js | MongoDB | Mongoose | Postman | MongoDB Compass | VS Code | Git & GitHub**

## 5. Learning Outcome

Gained practical experience in **backend development, REST APIs, MongoDB integration, CRUD operations, data validation, and error handling**.
